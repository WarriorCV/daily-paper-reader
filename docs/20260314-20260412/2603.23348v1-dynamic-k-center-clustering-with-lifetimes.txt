# Dynamic k-center clustering with lifetimes 

Simone Moretti 1 * Paolo Pellizzoni 2 * Andrea Pietracaprina 1 * Geppino Pucci 1 * 

## Abstract 

The k-center problem is a fundamental clustering variant with applications in learning systems and data summarization. In several real-world scenar-ios, the dataset to be clustered is not static, but evolves over time, as new data points arrive and old ones become stale. To account for dynamic-ity, the k-center problem has been mainly studied under the sliding window setting, where only the 

N most recent points are considered non-stale, or the fully dynamic setting, where arbitrary se-quences of point arrivals and deletions without prior notice may occur. In this paper, we intro-duce the dynamic setting with lifetimes , which bridges the two aforementioned classical settings by still allowing arbitrary arrivals and deletions, but making the deletion time of each point known upon its arrival. Under this new setting, we devise a deterministic (2 + ε)-approximation algorithm with eO(k/ε ) amortized update time and mem-ory usage linear in the number of currently ac-tive points. Moreover, we develop a deterministic 

(6+ ε)-approximation algorithm that under “tame” update sequences has eO(k/ε ) worst-case update time and heavily sublinear working memory. 

## 1. Introduction 

Clustering, which is used to summarize and to group to-gether data, is one of the most widely studied primitives in machine learning and data mining (Hennig et al., 2015). A common clustering task is k-center clustering, where, given a set of data points X from a metric space (U, d ), one needs to select k centers from X such that the maximum distance from any data point at hand to its closest center is minimized. This problem is well-known to be NP-hard (Gonzalez, 1985), so approximation algorithms are sought. Motivated by many real-world scenarios, recent years have witnessed a growing interest in devising dynamic clustering

algorithms (Chan et al., 2018; Bhattacharya et al., 2024; Cohen-Addad et al., 2016), where the set of data points is not fixed and static, but rather changes dynamically, allowing new points to be inserted and some points to be deleted. For example, the need for clustering dynamic data may arise for tracking stored products in a warehouse (Kalkha et al., 2024; Srinivasan & Moon, 1999), for analyzing the behaviors of active users in a web community (Morrison et al., 2012), or studying evolving populations (Gajer et al., 2012). Dynamic clustering focuses on the analysis of (unbounded) sequences of updates (i.e., insertions or deletions of points), focusing, at any time, on the instance defined by the active set of points, namely, those that have been inserted and not yet deleted. The two main dynamic settings that allow both insertions and deletions are the sliding window setting and the fully dynamic setting. In the sliding window setting, the active set consists of the N most recent points, that is, whenever a new point is inserted, the oldest one is deleted (Cohen-Addad et al., 2016; Borassi et al., 2020). The focus is on designing algorithms which use o(N ) memory, hence avoiding storing the entire active set. In the fully dynamic setting, both insertions and deletions are arbitrary: at any time, a new point may be inserted or an active point may be deleted (Chan et al., 2018; Bhattacharya et al., 2024). This latter setting is more general and therefore more challeng-ing than the former, but known approaches typically allow memory usage linear in the size of the active set, shifting the focus to approximation quality and fast update times. In this paper, we introduce a third setting, offering a middle-ground between the aforementioned two, which we refer to as the dynamic setting with lifetimes . In this setting, when a point is inserted, an arbitrary lifetime is also specified, and the point will be deleted as soon as the lifetime expires. This is more general than the sliding window setting, where the lifetimes are equal and fixed for all points, but it is less general than the fully dynamic one, where deletion times are not known in advance. The dynamic setting with lifetimes has several relevant real-world applications, including the aforementioned ones. For example, items might arrive at a warehouse with a pre-assigned specific departure time, and subscriptions to a web community might have known expiration dates. 1

Additional related work Several works have tackled k-center in the fully dynamic setting (Chan et al., 2024; Bateni et al., 2023), including focusing on variants with outliers (Chan et al., 2024; Biabani et al., 2024), on low-dimensional spaces (Goranci et al., 2021; Pellizzoni et al., 2023; Gan & Golin, 2024), on minimizing recourse (Lacki et al., 2024; Bhattacharya et al., 2025; Forster & Skarlatos, 2025), and on graphs (Cruciani et al., 2024). Dynamic settings akin to the one with lifetimes have been ad-dressed recently, including the deletions-look-ahead model (Peng & Rubinstein, 2023), the general expiration stream-ing model (Blank et al., 2025), and models with predicted deletion times (Liu & Srinivas, 2024), see also Appendix A.

The dynamic setting with lifetimes Let X be a dataset whose subsets represent instances of a given optimization problem 1. In the dynamic with lifetimes setting , each ele-ment p ∈ X is endowed with an arrival time tarr (p) ∈ N

Also, we assume that an oracle communicates the arrivals of elements from X, ordered by their arrival time. An algo-rithm in this dynamic setting maintains a suitable represen-tation of Xt, by running a primitive UPDATE (p) upon the arrival of a new element p, and, at any time t, is able to com-pute a solution to the given computational problem, with respect to instance Xt, by running a primitive Q UERY (t).The goals that the algorithm should pursue are: 1. Good approximation of the optimal solution for Xt;2. Query time sublinear in |Xt|;3. Update time (possibly amortized) sublinear in |Xt|;4. Memory requirements at most linear in |Xt|

(Optionally : memory sublinear in |Xt|). Note that the main requirements are shared with both the fully dynamic and sliding window settings. The optional one, typical of the sliding window but not of the fully dy-namic setting, makes the algorithm design more challenging. Under this requirement, our setting is analogous to the gen-eral expiration streaming model , which was recently intro-duced in Blank et al. 4.3. Comparison with related work 

The memory and time complexities of algorithm presented in this section depend on the tameness of the update se-quences. These gains, however, come at the cost of a (slightly) worse approximation. When focusing on sublinear memory, our setting generalizes the sliding window model. Indeed, our algorithm extends the sliding window one of Cohen-Addad et al. (2016) by allowing arbitrary deletions. Despite the increase in general-ity, we match the same memory and time complexities when 

H = 0 . The recent preprint by Blank et al. (2025) also ad-dresses a similar generalized setting while focusing primar-ily on the memory requirements, as common in the stream-ing setting. However, it comes with a great cost in terms of the approximation factor, which grows linearly with k instead of being constant.

## A. Comparison with settings akin to the one with lifetimes 

Dynamic settings akin to the one with lifetimes introduced here have recently been proposed in the literature. Peng & Rubinstein (2023) address the deletions-look-ahead dynamic model, where the order of deletions of elements of the active set is known to the algorithm, like in the dynamic setting with lifetimes. They show that any incremental algorithm with worst-case update time Tu and query time Tq can be turned into an algorithm that can support both insertions and deletions in the deletions-look-ahead model with O(Tu log |X|) amortized update time, O(Tq ) query time, and Θ(log |X|)

memory. Crucially, the total number of elements that are inserted or deleted from the active set, i.e., |X|, can be exponentially bigger than the number of active elements at any point in time, i.e., max t |Xt|. Because of this, the proposed technique would fail the requirement of the dynamic setting with lifetimes asking update times sublinear in |Xt|.The recent preprint of (Blank et al., 2025) introduces the general expiration streaming model , which generalizes the sliding window model by allowing for arbitrary deletion orders, yet elements are endowed with their deletion time, like in the dynamic setting with lifetimes. Since this model stems from the streaming one, the focus seems to be primarily on sublinear memory usage. For a comparison with their algorithm, see Section 4.3. Finally, several settings have been introduced to inform dynamic algorithms with predicted or uncertain (rather than exact) deletion times of elements, inserting these works in the broader algorithms with predictions framework (Mitzenmacher & Vassilvitskii, 2022). Among these, Liu & Srinivas (2024) utilizes the predicted-update dynamic model , extending the setting of Peng & Rubinstein (2023) to allow for predicted deletion times, and show that also under this setting some incremental or offline algorithms can be turned into fully-dynamic ones, with O(polylog |X|) overhead. Moreover, both Brand et al. (2024) and Henzinger et al. (2024) endow fully dynamic algorithms with predicted deletion times of points, in a setting akin to the predicted-update dynamic model of Liu & Srinivas (2024), but focus on graph problems. 

## B. Limitations and future work 

In this paper, we developed two algorithms for k-center in the newly introduced dynamic setting with lifetimes . While the introduction of this setting and the new algorithms offer several advantages over algorithms for the fully dynamic or the sliding window setting (in terms of efficiency and generality, respectively), we envision that future work can address several limitations of the present work. First, developing lower bounds on the trade-offs between approximation guarantees and time complexities for k-center in the dynamic setting with lifetimes, and understanding how they differ from the ones in the fully dynamic setting (e.g., the ones presented in Bateni et al. (2023)), would be a major step forward for the field. Additionally, it would be interesting to understand how these lower bounds change under the requirement of sublinear working memory (i.e., making the dynamic setting with lifetimes analogous to the general expiration streaming model (Blank et al., 2025)), and how they relate to the ones in the sliding window model (Cohen-Addad et al., 2016). Moreover, as for the fully dynamic setting, the dynamic setting with lifetimes allows for a definition of recourse , defined as the number of changes (i.e., C1△C2) made to the cluster centers after each point insertion or deletion (Lattanzi & Vassilvitskii, 2017). Both the algorithms we present here have trivial O(k) recourse, and developing algorithms with o(k)

recourse is an interesting research direction. In the fully dynamic setting, Forster & Skarlatos (2025) developed an algorithm that yields a 50 -approximation with optimal recourse of 2 and eO(poly( |X|)) update time, while Bhattacharya et al. (2025) developed an algorithm that yields a 20 -approximation with O(1) recourse and eO(k) update time. Understanding how these trade-offs can be improved in the dynamic setting with lifetimes would be a major development. Finally, several extensions to the k-center problem can be tackled in the dynamic setting with lifetimes. For example, the algorithms could be extended to deal with variants of the problem, including dealing with outliers (Biabani et al., 2024), diversity maximization (Wang et al., 2023), and fairness constraints (Ceccarello et al., 2025). Moreover, techniques for low-dimensional metric spaces could be used to improve the approximation guarantees under memory constraints (Pellizzoni et al., 2022a) or to obtain O(1) update times (Gan & Golin, 2024; Pellizzoni et al., 2023). 11 Dynamic k-center clustering with lifetimes
